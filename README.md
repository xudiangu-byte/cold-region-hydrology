# cold-region-hydrology

Cold Region Hydrology and Hazards Research Group Website

寒区水文与灾害研究团队主页，纯静态站点，由 GitHub Pages 从 `main` 分支根目录发布。

访问地址：https://xudiangu-byte.github.io/cold-region-hydrology/

## 修改后如何发布

本站不需要安装 git，直接用 GitHub 网页上传即可：

1. 打开仓库页面，点右侧 **Add file → Upload files**
2. 打开桌面上的 `impact-lab-上传` 文件夹，全选里面所有内容，拖进上传区
3. 等文件列表出现后，点下方 **Commit changes**
4. 等 1–2 分钟，Pages 自动重新构建

若浏览器仍显示旧版，按 `Ctrl + F5` 强制刷新——HTML 与 CSS 会被浏览器缓存。
